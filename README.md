# 📌 Project Overview

**LevelUp AI** is a Full-Stack Fitness Management Web Application built using **Flask, MySQL, HTML, CSS, JavaScript, and Chart.js**.

This project helps users manage:

- 👤 User Registration
- 🏋️ Workout Tracking
- 🎯 Goal Management
- 📝 Fitness Posts
- 🤖 AI Recommendations
- 👥 Followers System

It also demonstrates strong **DBMS concepts** like:

✅ CRUD Operations  
✅ JOIN & SELF JOIN  
✅ Aggregation Functions  
✅ Dynamic Queries  
✅ Search Operations  
✅ Validation  
✅ Group By  
✅ Auto Update System

# ✨ Features

## 👤 User Management

- User Registration  
- User Listing  
- Search by Username / Email / Full Name  
- Delete Users  
- Workout Count per User using Aggregation  

## 🏋️ Workout Management

- Add Daily Workouts  
- Exercise Name  
- Muscle Group  
- Weight Used  
- Reps & Sets  
- Workout History  
- Delete Workouts  
- Chart.js Workout Statistics  

## 📊 Dynamic Aggregation

Supports:

- COUNT()  
- SUM()  
- AVG()  
- MAX()  
- MIN()  

Users can dynamically choose:

- Group By Column  
- Aggregate Column  
- Aggregate Function  

## 📝 Posts Management

- Create Fitness Posts  
- View Posts  
- Delete Posts  

## 🎯 Goals Management

- Create Goals  
- Set Target Value  
- Deadline Tracking  
- Update Goal Progress  
- Auto Status Update  

## 🤖 AI Recommendations

- Personalized Fitness Tips  
- Category-Based Recommendations  

## 👥 Followers System

- Follow Other Users  
- View Followers  
- Delete Followers
